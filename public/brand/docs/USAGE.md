# KasarTech.ai Asset Usage

Use SVG masters for website/navbar/footer whenever possible.
- Light logo: logo/kasartech-logo-light.svg
- Dark logo: logo/kasartech-logo-dark.svg
- White logo: logo/kasartech-logo-white.svg
- Symbol-only: logo/kasartech-symbol.svg
- Browser favicon: icons/favicon-16.png, favicon-32.png, favicon-48.png, favicon.ico
- Apple icon: icons/icon-180.png
- PWA icon: icons/icon-192.png and icons/icon-512.png
- Dark app icon: icons/icon-dark-512.png
- White app icon: icons/icon-white-512.png
- Social preview: social/og-image.png

For navbar/footer, prefer symbol-only SVG + live HTML text in Inter rather than flattened wordmark text.
